# bcstarts.org 운영 지침 (요약)

목표: 글 개수가 많은 블로그가 아니라 **직접 만들어보고 실패하고 비교한 실전 제빵 데이터베이스**.

애드센스 승인은 그 결과다. 게시물 수 증가를 성공으로 치지 마라.

## 새 URL 금지 (기본)

새 글을 쓰기 전에 기존 글을 **유지 / 수정 / 통합 / 삭제**로 분류한다.
아래 5개 중 3개가 불확실하면 새 URL을 만들지 않는다.

1. 검색할 사람이 있는가
2. 기존과 의도가 겹치지 않는가
3. 이 글만의 정보가 있는가
4. 직접 경험·실험을 넣을 수 있는가
5. 합치는 편이 낫지 않은가

글자 수 목표(2000자 등)로 분량을 채우지 마라. 같은 문장 반복 금지.

## 작업 순서

1. 전수 조사  2. 미래 날짜  3. 반복 제거  4. 얇은 글 통합
5. 핵심 보강  6. 실사 사진(사용자 제공만)  7. 허브·내부링크
8. 카테고리/중복 URL/기술 SEO  9. GSC(사용자)  10. 재신청

## 통합 우선

짧은 주방 글(콘센트·타이머·작업대·식힘망·전자레인지·냉장고·창가·난방)은
개별 URL보다 **한 편의 공간 가이드**로 합친다.
작은 R&D는 실전 정리 허브로 묶는 것을 먼저 검토한다.

삭제한 URL은 관련 허브로 리다이렉트한다.

## 날짜

오늘보다 미래 발행일이 보이면 안 된다. 실제 올린 날만 표시.

## 데이터

경험·온도·시간·실패·사진은 사용자가 준 것만 쓴다. AI가 만들어내지 마라.
경력 과장 금지. 「실사 아님」 같은 캡션도 넣지 마라.

## 허브

카테고리는 `?cat=` 중복 색인을 피하고 `/categories/{slug}/` 정식 URL + canonical.
